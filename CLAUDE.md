# Stable

A Postgres-protocol proxy written in Pony. Acts as a server to `psql`-style
clients and as a client to a real Postgres backend.

## Load `pony-skills` at the start of Pony work

At the start of work in a Pony project, load the `pony-skills` skill — a
routing index that tells you which `pony-*` skill to load for each task. This
one trigger covers all of the Pony skills.
